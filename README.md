# 🦊 Trade Fox — Landing Page

Landing page de **Trade Fox**, tienda de consolas, videojuegos, mandos y accesorios.

![Tecnologías](https://img.shields.io/badge/HTML5-Tailwind_CSS-orange) ![Estado](https://img.shields.io/badge/Estado-Activo-success)

## ✨ Características

- 🎨 Diseño **Dark Mode** con acentos en naranja fox
- 📱 100% **responsivo** (móvil, tablet, escritorio)
- 🛒 Catálogo **dinámico** cargado desde Google Sheets
- 💬 Botones de **WhatsApp** en cada producto
- ⚡ HTML + Tailwind CSS + JavaScript vanilla (sin frameworks)

## 📂 Estructura

```
TradeFox/
├── index.html                      # Página principal
├── netlify.toml                    # Configuración de publicación
├── .gitignore                      # Archivos ignorados por Git
├── README.md                       # Este archivo
└── COMO-USAR-GOOGLE-SHEETS.txt     # Guía para gestionar productos
```

## 🚀 Publicación

La web se publica automáticamente en Netlify cada vez que se hace un cambio en GitHub.
Ver la guía completa en: `PUBLICAR-WEB-GITHUB-NETLIFY.txt`

## 🛠️ Gestión de productos

Los productos se gestionan desde Google Sheets — sin tocar código.
Ver: `COMO-USAR-GOOGLE-SHEETS.txt`
